# Roadmap

## Phase 0 — Foundation (this repository)

- Product identity and positioning
- Next.js app shell and canonical shoe routes
- Structured review taxonomy
- Supabase schema + RLS
- Auth-ready flow
- Comparison prototype
- Seed catalog methodology
- CI/tests/docs

## Phase 1 — Closed beta

- Connect production Supabase
- Admin catalog importer/editor
- Real account/profile onboarding
- Review creation/editing
- Rotation/wishlist UI
- Search/filtering
- Replace synthetic community UI data with database aggregates
- Seed 100–200 Indonesian-relevant shoes with provenance
- Recruit first 100 runners

Exit criterion: 300+ valid structured shoe experiences across 50+ models.

## Phase 2 — Public Indonesia launch

- SEO pages and structured metadata
- Similar-shoe pages and comparison URLs
- Indonesian retailer price ingestion
- Price history and alerts
- Reviewer credibility/helpfulness
- Local-brand launch coverage
- Cohort insights: “runners like you”

Exit criterion: repeat organic traffic plus enough cohort density for useful personalized signals.

## Phase 3 — Preference engine

- Personalized Runned Match
- Rotation recommendations
- Shoe transition graph (“what owners buy next”)
- Fit/width issue prediction
- AI natural-language query over proprietary Runned data
- B2B aggregated market insights with strict privacy controls

## Explicit non-goals at launch

- Building a physical shoe testing lab
- Becoming an ecommerce retailer
- Generic running coaching
- Social feed for its own sake
- Scraping unverified specifications into the canonical catalog
