# Runned Product Foundation

## Positioning

**Runned — The running shoe database built by runners.**

Runned should become the canonical Indonesian destination for answering two questions:

1. What is this shoe?
2. Is this shoe good for a runner like me?

## Beachhead

Indonesia-based road runners researching shoes in the Rp700k–Rp5m+ range, especially runners who currently combine YouTube/TikTok reviews, marketplace listings, manufacturer pages and peer recommendations before purchasing.

## MVP jobs to be done

- Search and discover a shoe.
- Understand verified specifications and source quality.
- Understand how runners perceive the ride and fit.
- Compare two shoes consistently.
- Create a runner profile.
- Review a shoe through structured dimensions.
- Track current, past, race and wishlist shoes.
- See Indonesian MSRP and eventually current retailer pricing.

## Structured review dimensions

1. Overall rating
2. Softness
3. Energy return
4. Stability
5. Fit width
6. Toe-box room
7. Heel lockdown
8. Grip
9. Durability
10. Breathability
11. Value
12. Would buy again

Reviews also preserve shoe size, distance run in the shoe and runner profile context.

## Trust rules

- Never merge synthetic/demo ratings with real community data.
- Every objective specification should carry provenance and verification status.
- Retail/sponsored relationships never alter community scores.
- Sponsored placements must be explicitly labeled.
- Brands cannot pay to delete legitimate negative reviews.

## North-star metric

**Useful shoe experiences contributed per month** — a completed structured review attached to a meaningful runner profile.

Traffic and affiliate GMV are downstream metrics; preference-graph density is the core asset.
